# drupify

A prototype learning platform for Drupal developers: study modules with user
progress tracking. Built over a week in December 2024 and parked.

Monorepo: Next.js web app, NestJS + TypeORM + Postgres backend, shared
TypeScript package.

Status: unfinished prototype, kept public as a snapshot. The users CRUD, error
handling, and progress endpoint work. The content itself never landed.
